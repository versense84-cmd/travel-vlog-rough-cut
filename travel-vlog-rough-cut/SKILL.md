# 旅行 Vlog 自动初剪

交付一条可继续编辑的达芬奇粗剪时间线。成片以精彩合集开场，正文按旅行顺序交代去了哪里、做了什么。

## 1. 整理素材

确认目标项目、素材范围、参考成片和已录配音。按拍摄时间、地点和设备整理素材，区分相机、Pocket、无人机、手机、独立录音、地图和旧照片。多设备时钟有偏差时，用场景与同期声校对顺序。使用新时间线，保留源素材和参考版本。

素材在云盘时，使用用户已配置并授权的下载方式，把文件取到剪辑电脑并检查完整性。云盘、远程执行和达芬奇连接由运行环境提供。遇到缺少连接、权限或素材时，说明具体阻塞，并交付当前可验证的部分。

## 2. 先搭故事和声音

转写 Pocket 口播、第一视角讲话、向导讲解、对话和已有配音。记录说话人、原文、语言、素材 ID 和源时间码。按旅行顺序整理正文，保留能交代经历、解释画面或体现现场反应的讲话。优先使用已有录音和配音。

需要补写旁白时，按以下分支选择音色：

- 用户提供了可调用且授权使用的音色时，用它生成补充旁白。
- 用户没有提供音色时，查找免费且许可适合预期用途的音色，核对来源和发布条款后生成。整期保持统一。按运行环境的权限处理需要上传的文本或音色样本。

## 3. 按语义剪画面

看候选素材的代表帧和实际片段。为每段旁白或现场话记录其指向的人、地点、物件或动作，再选主体匹配的镜头。相机优先拍主体与细节，Pocket 保留第一视角和人物反应，无人机交代地理关系和空间尺度。

长段 Pocket 讲话可先给说话人，让原声继续走，切到对应的相机画面或航拍，在表情、动作或互动有价值时切回来。剪点跟随话意变化，检查切入切出时原声连续、人物口型同步。保持镜头来源多样，同时优先满足内容关联。

例如「河流穿过老城」配能同时看清河道与两岸的镜头。「这座教堂的管风琴」配同一座教堂里的管风琴。「这些建筑背后的历史」配建筑主体，讲到战时破坏再切已核对的旧照。背景偶然出现建筑，无法支撑一个以商品为主体的镜头。

## 4. 从正文提炼精彩开场

先剪通按时间顺序展开的正文，再从全程挑选能兑现开场看点的片段。用已有配音或一句有钩子的现场话带出重点，穿插多段视角不同的航拍、相机细节和 Pocket 现场画面。让每次切换带来新信息。开场时长跟随内容，结束后自然接回旅行第一站。

## 5. 按实际拍摄格式做一级还原

对每条入选实拍镜头建立四个调色节点：

1. 输入曝光和白平衡。
2. 转换前的基础修正。
3. 色彩空间转换（CST）。
4. 转换后的对比度、饱和度和跨机位匹配。

第 3 节点的输入色域和伽马以拍摄设置、文件元数据和画面核验为依据，输出与时间线的工作空间和色彩管理一致。索尼 S-Log3 核对实际 S-Gamut，手机 HDR 区分 HLG 和 PQ，大疆 Log 核对实际录制模式，佳能 C-Log 核对具体版本及色域。已经是 Rec.709 的素材保留并跳过第 3 节点的转换。发灰是检查线索，遇到格式不明就标记待确认。检查项目是否已自动转换输入，避免重复还原。抽看相机、手机、Pocket 与无人机之间的剪点。

## 6. 写入全片字幕和地点介绍

- **对白和旁白**放在达芬奇原生字幕轨。按粗剪剪点对齐，覆盖片头到最后一句有效讲话，包括配音、Pocket 同期声和向导讲解。外语翻译成中文便于剪辑，按用户需要附原文。导入后核对时间线起始时间码、轨道启用状态和字幕实际位置。
- **地点介绍**在整理文本时标出适合上卡的句子。根据画面、行程和地点线索确认对象，再查证一条与镜头有关的信息。白字名称用较粗的字体原生字重，说明用较细字重。放在有留白的位置，避开人物、建筑主体和底部字幕。标题动效和透明文字素材默认使用 HyperFrames，设置明确字距，检查渲染帧后放进达芬奇独立轨道。无法确认的名称留时间线标记。

## 7. 验收并保存

使用当前可用的达芬奇连接或脚本接口写入时间线，保存后回读轨道和片段位置。实际预览开场、正文代表段和结尾，确认开场之后接入时间顺序正文，画面主体对应当前话意，同期声连贯，外语字幕能看懂，字幕持续到最后一句有效讲话，地点介绍和四节点调色已落到时间线上。检查黑帧、离线素材和明显的跨机位色差。用时间线标记记录听不清的对白、待确认的地名和色彩格式。汇报项目名、时间线名及任何尚未落轨的部分。
